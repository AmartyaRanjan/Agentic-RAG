The system at a glance

Two processes share two stores. The API accepts files and answers status requests. A separate RQ worker does the slow work, and only the worker ever imports Docling.

Every function, class and method in app/. Hover or focus a node to see what it calls and what calls it; click to pin it. Dashed outlines have no caller inside app/.

What happens on POST /documents

The whole upload path lives in upload_document. It hashes and size-checks while it streams, so a rejected file is cut off at most one chunk over the limit.

What the worker does with a job

Document-level routing is the default. Page-level routing runs only when PDF_ROUTING=page and the pages disagree about OCR, and it falls back to whole-document OCR if anything does not check out.

How one page is classified

_classify_page in pdf_detector.py. It never renders the page, never runs OCR and never decodes an image. It counts extracted characters and looks at image sizes in the page's resource dictionary.

Data structures

What is stored in SQLite, what travels in memory between the detector and the converter, and the states a document moves through.

documents

One row per accepted upload. Created by register_upload, updated by update_status and set_job_id.

ColumnTypeMeaning

document_pages

One row per PDF page. Written by save_pages, which replaces a document's rows in one transaction. Read by get_pages.

Loose ends visible in the code

Unused inside app/

  • registry.create_document was replaced by register_upload and has no caller.
  • convert.convert_document is a convenience wrapper that nothing calls yet.
  • PdfInspection.sampled, digital_ratio and all_digital are only used by tests; routing reads page_ocr instead.
  • queue.py imports load_dotenv but never calls it.

Not built or not wired

  • chunk.py, embed.py, pipeline.py, db/qdrant.py and core/config.py are empty files.
  • The worker discards the Docling document after saving page rows, then marks the document completed.
  • PDF_ROUTING is read straight from the environment inside convert.py.
  • requirements.txt lists neither docling nor pypdf.
